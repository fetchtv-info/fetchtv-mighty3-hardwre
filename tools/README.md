## Project Supporting Files

Brief description of the tools published:

| file | description |
|---|---|
| ./bolt_console.py | Semi-automates getting the UART console on the Hybroad STB |
| ./fetch_inject.py | Sends selected javascript pages to the STB via HTTPS (MITM). |
| payload_readini.js | Reads the yx_config_user.ini from the STB |
| payload_persist.js | Installs helper scripts for remote dev access without BOLT bootloader access |

Instructions for use are in each file. Please read before running on your own systems.
